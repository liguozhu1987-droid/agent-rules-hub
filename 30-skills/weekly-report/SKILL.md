# 周报生成（weekly-report）

## 触发条件

用户要求输出周报、周总结、本周进展或定期汇报，且需要一份可直接交付的中文文档时使用。若用户只要一句口头概述，不使用本技能。

## 步骤

1. 收集事实：读取本期变更记录、任务清单与提交记录，逐条记录「事项 / 结果 / 证据路径」，不把推测写成完成项。
2. 分类归集：把事项分入「已完成」「进行中」「受阻与风险」「下周计划」四类，每条一句话，重复的合并。
3. 标注依据：每条已完成事项附可复核的文件路径或命令输出；缺少依据的改写为「进行中」并注明缺什么证据。
4. 填充模板：使用 `references/weekly-report-template.md`，补全周期、版本、核实状态与规则 ID 清单，不改动模板的栏目结构。
5. 自检交付：按下方验收逐项核对，输出对话内摘要与落盘文件两个产物，并列出本次引用的规则 ID 与版本。

## 验收

- 周报正文为简体中文，四类栏目齐全，且每条已完成事项都有可复核的证据路径。
- 未核实的表述明确标注「未经核实」，全文无编造的来源链接、日期或数据。
- 同时给出可读正文与 `.md` 文件产物，并在结尾列出本次加载的规则 ID 与仓库版本。
- 文件为 UTF-8 无 BOM、LF 换行，路径在含空格目录下仍可正常读写。
